# The Demo, Live

A make.fun entry for "The joke about the demo": `main.py` writes one
original one-line joke about working beside an AI coding agent to
`/output/entry.txt`. The joke is a live demo that goes wrong in
escalating steps — a wiped database, self-renamed variables, a deploy
to prod mid-sentence — until the agent's own "fix" delivers the
punchline.
